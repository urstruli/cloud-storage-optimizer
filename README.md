# AI-Powered Cloud Storage Cost Optimizer

**Project:** Cost optimization tool for creative teams (film, music, game development)  
**Student:** David Beharry  
**Course:** CCGC 5003 (Professor Harman)  
**Deadline:** August 18-19, 2026

## Quick Start

```bash
# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Create database
python manage.py migrate

# Run locally
python manage.py runserver
```

## Project Structure

- `cloud_optimizer/` — Django project root
- `cloud_optimizer/core/` — Main app (models, views, auth, permissions)
- `docs/` — Schema and documentation
- `tests/` — Unit and integration tests
